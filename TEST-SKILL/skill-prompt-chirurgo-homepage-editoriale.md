## Obiettivo generale

Acquisire proprietari (vendita, affitto, reddito, gestione, valutazione, consulenza) **senza** penalizzare acquirenti/inquilini e ricerca annunci.

Homepage: in 3 secondi il proprietario capisce che Righetto può aiutarlo con persone reali.

## Homepage — checklist operativa

### Hero (FASE 3)
- [ ] Foto **reali** team (Gino/Linda) — no stock/AI
- [ ] Sfondo **luminoso** — overlay minimo per leggibilità
- [ ] H1 owner-first: «Hai un immobile a Padova o in provincia?»
- [ ] Sottotitolo: valutare, vendere, affittare, gestire, reddito
- [ ] CTA primaria → `landing-valutazione` («Valuta il tuo immobile»)
- [ ] CTA secondaria → `proprietario-immobile` o servizi owner

### Doppio percorso (FASE 4)
- [ ] «Possiedi un immobile?» → sezione proprietari / valutazione
- [ ] «Cerchi un immobile?» → `#ricerca` / `immobili`
- [ ] Ricerca annunci **mantenuta** e funzionante

### Sezione proprietario (FASE 5)
- [ ] Percorsi distinti: vendere · affittare · valutare · reddito · gestione
- [ ] Solo link a pagine/servizi **reali** — no funnel fittizi

### Gerarchia (FASE 6 — indicativa)
1. Identificazione owner
2. Cosa vuoi fare
3. Valutazione/consulenza
4. Fiducia (E-E-A-T)
5. Immobili disponibili
6. Processo
7. Recensioni
8. Blog/approfondimenti

### Tecnico (FASE 7–8)
- Contatori claim verificati · no recensioni duplicate · responsive · no refactor distruttivo
- Test percorsi: venditore · indeciso · locatore · acquirente

## Regola editoriale — lunghezza articoli

**Riferimento:** ~2.500 parole · **tolleranza ±20%** (2.000–3.000) come fascia, **non obbligo meccanico**.

### Gerarchia priorità (dalla più alta)
1. Veridicità e fonti
2. Coerenza tema
3. Utilità lettore
4. Originalità ragionamento
5. Contesto Padova/Veneto / Righetto
6. Completezza effettiva
7. SEO/struttura
8. **Lunghezza** (ultima)

### Assolutamente vietato
- Paragrafi inutili · ripetizioni · sezioni solo per word count
- «Note operative» / «Further reading» senza valore
- FAQ/conclusioni che ripetono tutto
- Elenchi artificiali · esempi fittizi · **expand_body filler**
- Copia parafrasata di notizie/fonti

### Pubblicazione sotto soglia
Se l'articolo è **completo, verificato, utile** e non può crescere senza filler → **pubblicare** (es. 1.200–2.300 parole utili).

### Controllo pre-publish (8 domande doc)
1. Risponde alla domanda del lettore?
2. Aggiornato?
3. Informazioni concrete?
4. Ripetizioni concettuali?
5. Sezioni solo SEO/lunghezza?
6. Potrebbe essere più breve senza perdere valore?
7. Formule ripetitive da altri articoli?
8. Further reading / note operative superflue?

**Meglio 2.100 parole utili che 2.500 con ripetizioni.**

### Metodo elaborazione (10 passi doc)
Argomento → fonti → confronto fatti → anti-doppioni sito → angolo nuovo → conseguenze pratiche → servizi Righetto se naturale → scrittura originale → rilettura anti-filler.
