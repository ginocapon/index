# P0 sicurezza — 24 novembre 2026

Intervento per chiudere i punti critici dell’audit gestionale (RLS WhatsApp, RPC admin, superfici admin, 2FA, note email marketing / score-lead).

**Importante:** le modifiche SQL in questo intervento **non** sono state applicate automaticamente al database live. Gino (o chi ha accesso al pannello Supabase) deve eseguirle a mano dopo aver approvato il merge.

## Cosa cambia (in italiano semplice)

1. **Tabelle WhatsApp** (`whatsapp_personal_config`, `whatsapp_draft_config`, `whatsapp_personal_audit`): attivata la protezione RLS. Solo un account admin autenticato può leggerle/modificarle; il pubblico no.
2. **Funzioni admin** (attiva/disattiva annuncio, WhatsApp interno, moduli, ecc.): non sono più richiamabili “da anonimo”. Servono login admin. Restano pubbliche solo le funzioni necessarie al sito (Linda, disiscrizione newsletter, alcune funzioni aste con token).
3. **Pagine interne** (`scraping`, `bookmarklet-helper`): richiedono login admin prima di mostrare il contenuto. `admin-kb` aveva già il login; aggiunto blocco in `robots.txt`.
4. **2FA**: il codice segreto è legato all’utente, non si disattiva più con un click senza controllo, QR generato in locale (niente servizi esterni). Se il 2FA è attivo, dopo la password serve il codice dell’app Authenticator.
5. **Email marketing / score-lead**: avvisi chiari in admin e nella config — le tabelle campagne e la funzione edge score-lead non sono ancora sul DB live; non sono bug di sicurezza bloccanti ma vanno saputi.

## Come applicare il SQL (Supabase)

1. Apri [Supabase Dashboard](https://supabase.com/dashboard) → progetto **righetto-immobiliare**.
2. Vai su **SQL Editor** → **New query**.
3. Apri dal repository il file `sql/p0-security-2026-11-24.sql`.
4. Copia **tutto** il contenuto e incollalo nell’editor.
5. Premi **Run**.
6. Se compare errore su una tabella/funzione già sistemata, fermati e segnala il messaggio (non ripetere a caso).

Copia di backup dei pezzi separati:
- `supabase/migrations/20261124_p0_whatsapp_rls.sql`
- `supabase/migrations/20261124_p0_revoke_admin_rpc_anon.sql`
